# Исправления безопасности

Проверен исходный снимок `b1e1406e854d722898a4b5e6328f97aef548b086`.

- Удалены обфусцированная реклама при подключении, автоматические ответы на «когда» и случайные наказания в подарках.
- Фильтры выполняются до команд; исключения для модераторов, владельца и VIP единообразны.
- Удалён ложный «официальный список Twitch», содержавший нейтральные слова. Список настраивается владельцем.
- Нормализация повторов; два предупреждения за капс; ограниченные по размеру и времени кэши.
- Проверки прав привилегированных команд, собственных ключей таблицы команд, чисел, логинов, размеров запросов и результатов.
- Исходящие сообщения очищаются от переводов строк, ограничиваются по длине и частоте; slash-команды через повтор текста не отправляются.
- Баны, разбаны и удаление сообщений используют Helix API без ложного успешного результата от IRC-команд.
- Локальный API выключен по умолчанию, привязан к loopback, требует длинный ключ, использует timingSafeEqual и ограничивает частоту запросов.
- Третий варн через API действительно вызывает таймаут. Варны сохраняются в базе.
- Переводы и расчёт дуэлей выполняются в SQLite-транзакциях, повторное принятие дуэли не выплачивает выигрыш дважды. Списания условные, баланс ограничен.
- Ежедневные отметки атомарны; голосование не принимает голос за отсутствующую игру.
- Исправлены даты категорий, подключено обновление активного эфира, убраны фиктивные функции из документации.
- Запросы к Twitch ограничены по времени. Axios-ошибки не выводят заголовки с токеном. Отладочное логирование tmi выключено.
- Проверка OAuth при старте и каждый час; завершение по SIGINT/SIGTERM и при критических ошибках.
- Удалены неработающие напоминания о разбане; бессрочный бан не превращается в автоматический разбан.
- База автора и runtime-файлы не включены; секреты, базы и логи исключены из Git.
- Зависимости обновлены, удалены node-fetch и sqlite3 с устаревшей цепочкой native build; SQLite предоставляется Node.js 24.

Автоматические тесты проверяют опасные сценарии без подключения к реальному каналу. Это не гарантия отсутствия всех уязвимостей. Live-интеграция требует токенов владельца установки и отдельной проверки на тестовом канале.

Кулдауны команд, рулетки, жалоб, подарков и активности сохраняются в таблице `cooldowns`. Повторный вызов до истечения срока не обновляет его. Проверка и установка срока выполняются одним условным SQL-запросом; начисление очка активности и установка его кулдауна входят в одну транзакцию. Области ограничений разделены по каналу и логину. Добавлены тесты с отдельными процессами Node.js, повторным созданием диспетчера и параллельным начислением очков.

Режим `AUTOMOD_MODE=observe` включён по умолчанию: автоматические решения сохраняются без вызовов API наказаний, удаления сообщений или отправки предупреждений в чат. Режим `active` включается явно; некорректное значение режима останавливает запуск. Решения сначала сохраняются, затем выполняются; ошибка записи блокирует автоматические действия. Журнал ограничен 10 000 записями и очищается от событий старше 30 дней при записи. Ручная модерация и API не зависят от режима наблюдения.

Журнал ручной и активной автоматической модерации создаёт запись до отправки запроса. Инициатор чата берётся из Twitch tags; общий API-ключ записывается как `api_key`, без доверия к заявленному в теле запроса имени. Успех HTTP, отказ, неизвестный сетевой результат, локальные предупреждения и локальные сбои после подтверждения учитываются отдельно. Заголовки и сырые исключения не сохраняются. При ошибке начальной записи запрос блокируется; неоднозначные операции не повторяются автоматически.

Локальная панель использует существующий API-ключ, без хранения в браузерных хранилищах. Данные и команды требуют аутентификации; публичны только HTML/CSS/JS без конфигурации и секретов. Сетевой доступ ограничен loopback, проверяются Host и Origin, установлены CSP, запрет фреймов и no-store. Значения журнала выводятся через textContent. Команды и переключение режима требуют явного подтверждения; Escape и отмена не отправляют действие. Сохранённый режим имеет приоритет над стартовой переменной окружения; счётчики симуляции очищаются при его смене.

OAuth обновляется одним общим запросом после HTTP 401. Повтор исходного запроса разрешён только после явного отказа авторизации, один раз. Неоднозначные результаты мутаций не повторяются. Пара токенов сохраняется атомарно в исключённом из Git файле, без client secret. Владелец и scopes проверяются до использования нового токена. Сырые ответы обновления и сетевые ошибки не выводятся. При отзыве авторизации процесс завершает работу; обычный временный сбой проверки не завершает работающий процесс. Для чат-подключений используется динамический провайдер токена; Axios больше не захватывает токен при импорте.
